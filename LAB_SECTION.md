Pure HTML/CSS with original decorative SVG covers; no remote image requests, added JavaScript or package dependencies.

The available local source confirms an aiogram media bot with yt-dlp, FFmpeg, queued downloads/conversion and clip handling. No README or license was confirmed. The supplied repository URL is preserved with an access caveat; the section is deliberately labelled personal projects rather than open source.
